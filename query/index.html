게시글 연결은 (gall_id, post_no) 복합키입니다. post_no만으로 조인하지 마세요. FK는 로컬 DB의 선언이며 실행 시 검증 여부와는 별개입니다. 논리 연결은 고유성이나 FK 제약을 보장하지 않습니다.

actor_key / reporter_key는 uid: 또는 ip: 접두어를 해석해야 합니다. alarm.ref_id는 유형별로 보드 ID, 댓글 ID 또는 gall_id:post_no입니다. 이런 조건부 연결은 지도 선에 포함하지 않습니다.

가입 인증은 사용자 생성 전 정보입니다. 역할 테이블과 사용자 사이에는 FK가 없습니다. 로컬 SQLite 변환 시 보조 UNIQUE가 제거되었으므로 운영 DB 제약과 다를 수 있습니다. 이 페이지는 구조 조회와 SQL 초안 생성을 제공하며 실제 DB 레코드를 조회하지 않습니다.
