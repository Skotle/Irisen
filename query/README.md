# 테이블 관계 탐색기

`index.html`을 브라우저에서 열면 동작하는 독립 페이지입니다. 외부 패키지·CDN·DB 연결은 필요하지 않습니다.

Windows에서는 `run-query.cmd`를 더블클릭하면 Python 3로 로컬 서버를 실행하고 기본 브라우저에서 `/query/`를 엽니다. 사용 가능한 포트를 자동으로 선택하므로 기존 서버와 충돌하지 않습니다. 실행 창을 닫거나 Ctrl+C를 누르면 서버가 종료됩니다. Python 3가 필요하며 `py -3`, `python` 순서로 확인합니다.

프로젝트 루트에서 아래 명령을 실행하면 `/query/` URL로 볼 수 있습니다.

```powershell
python -m http.server 8091 --bind 127.0.0.1
```

접속 주소: http://127.0.0.1:8091/query/

기존 Spring 애플리케이션에 라우트를 등록하지 않는 독립 문서 UI입니다.

- 테이블 이름·컬럼·설명 검색 및 영역 필터
- 전체 노드 / 선택 테이블의 직접 이웃 보기
- 외래키 / 논리 관계 필터, 드래그 이동, 휠 확대, 화면 맞춤
- 테이블의 모든 컬럼, 기본키, 타입, NULL 여부 조회 (컬럼에 마우스를 올리면 기본값·참조 표시)
- 연결 버튼으로 대상 테이블 이동
- 컬럼·관계·행 수를 선택해 SELECT 및 LEFT JOIN SQL 생성, 복사
- URL 해시로 선택 테이블 유지 (예: `index.html#comment`)

SQL은 초안 생성만 하며 실행하지 않습니다. 실제 사용자 데이터는 포함하지 않습니다. 조인 결과는 연결 행 수에 따라 여러 행으로 늘어날 수 있습니다. 조건부 문자열 참조는 일반 조인 후보에 포함하지 않습니다.

## 스키마 갱신

검토된 `docs/table-relationships.md`를 고친 후 프로젝트 루트에서 실행합니다.

```powershell
python query/generate_schema.py
```

생성기는 문서의 테이블·컬럼·관계 목록을 읽어 `schema.js`를 갱신하고 연결 컬럼의 존재를 검증합니다. DB에 접속하거나 레코드를 읽지 않습니다. 현재 자료는 2026-09-09의 로컬 스키마와 코드 분석 기준이며 운영 MySQL과 다를 수 있습니다.
